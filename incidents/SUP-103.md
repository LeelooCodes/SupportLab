# SUP-103 — Returning customer receives server error

## Customer

LegacyWorks Ltd

## Report

A returning customer can be found in the system, but checking product feature access results in an internal server error.

Affected user:

`robin@legacyworks.example`

The customer account has existed for several years and has only recently become active again.

## Reported behaviour

User lookup succeeds.

Feature-access requests fail with a server-side error.

## Expected behaviour

The application should determine whether the customer's account is entitled to the requested feature.

## Support task

Investigate using:

- reproduction;
- application logs;
- TypeScript application flow;
- MongoDB document inspection;
- comparison with working customer accounts.

Determine:

- the root cause;
- whether the issue is isolated or systemic;
- whether existing data requires remediation;
- what longer-term preventative action should be taken.

Do not manually rewrite the customer document as the final solution.
