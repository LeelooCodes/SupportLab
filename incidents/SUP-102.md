# SUP-102 — Unexpected Audit Logs access

## Customer

Acme Analytics

## Report

A review of customer access has identified that a Pro customer appears able to access Audit Logs.

Affected user:

`alex@acme.example`

## Reported behaviour

The Audit Logs feature is accessible.

## Expected behaviour

Audit Logs should only be available where the account's configured entitlements permit it.

## Support task

Reproduce the issue and investigate the request path.

Determine:

- whether the MongoDB account data is correct;
- whether the behaviour affects other features;
- how the application decides whether access is permitted;
- where actual behaviour diverges from expected behaviour;
- the root cause;
- an appropriate systemic fix;
- how to test for regression.
