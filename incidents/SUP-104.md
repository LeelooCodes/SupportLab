# SUP-104 — One user cannot be found

## Customer

Orbit Retail

## Report

One employee cannot access the product because the application reports that the user cannot be found.

Affected user:

`taylor@orbit.example`

A colleague at the same organisation can use the application normally:

`jamie@orbit.example`

## Reported behaviour

Jamie can be retrieved successfully.

Taylor receives "User not found".

## Expected behaviour

Both users belong to the same active customer account and should be retrievable.

## Support task

Treat this as a "works for most users but not this user" investigation.

Determine:

- whether the issue can be reproduced;
- whether the account itself is healthy;
- what differs between the working and affected user;
- whether logs provide useful evidence;
- whether the problem originates in application behaviour or stored data;
- the root cause;
- whether fixing only the affected record is sufficient or whether a systemic fix is appropriate.
