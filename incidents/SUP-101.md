# SUP-101 — CSV Export unavailable for paying customer

## Customer

BluePeak Media

## Report

A customer reports that CSV Export is unavailable.

They state that their organisation is currently subscribed to the Pro plan and that the feature was expected to be available.

Affected user:

`nina@bluepeak.example`

## Reported behaviour

CSV Export returns an access-denied response.

## Expected behaviour

An active Pro customer should have access to CSV Export.

## Investigation

The issue was successfully reproduced using the feature-access API for `nina@bluepeak.example`.

The user record was present and active, ruling out a general user lookup or disabled-user issue.

Structured application logs showed that the request was evaluated as:

- feature: `exportCsv`
- subscription plan: `pro`
- result: denied
- reason: `entitlement_disabled`

The affected user's `accountId` was used to locate the corresponding BluePeak Media account in MongoDB.

The account was compared with a known-good active Pro account using MongoDB filters and projections.

BluePeak Media stored:

- subscription plan: `pro`
- subscription status: `active`
- `entitlements.exportCsv`: `false`

The healthy Pro comparison account stored `entitlements.exportCsv: true`.

## Root Cause

The user-facing failure was caused by inconsistent account data.

BluePeak Media was correctly configured as an active Pro subscription, but its CSV Export entitlement was incorrectly stored as disabled.

The TypeScript application correctly evaluated the stored entitlement and returned `entitlement_disabled`.

The investigation established the immediate cause of the incident but did not establish how the inconsistent entitlement originally entered the database.

## Resolution

A guarded TypeScript remediation script was used to update the affected MongoDB document with `updateOne()`.

The update required the document to match the expected investigated state before making any change:

- correct account ID;
- Pro subscription;
- active subscription status;
- CSV Export currently disabled.

The script updated only `entitlements.exportCsv` and the account's `updatedAt` timestamp.

The MongoDB operation was validated using both `matchedCount` and `modifiedCount`.

## Validation

Post-fix validation confirmed:

- the MongoDB document stored `entitlements.exportCsv: true`;
- the original customer request returned `allowed: true`;
- structured application logs recorded successful feature access;
- another Pro account continued to receive CSV Export access;
- a Free account continued to be denied CSV Export access.

## Preventative / Systemic Improvement

Introduce automated account-health diagnostics that identify subscription and entitlement combinations that conflict with expected plan configuration.

This would allow support engineers to detect entitlement inconsistencies earlier and reduce investigation time for similar incidents.
